- `probe-group report` and `probe-group record` judge a run with the probe config and enabled mod list it started with (each run keeps a copy of its config beside its manifest), not the rig's current ones, which the next `install` replaced: `record` without `--accept` could record the next group. Both say which config they read, refuse when an older run's config is gone, and `report --config FILE` judges with a given config.
