- Research report (ROADMAP-3 82.1, 82.2): new `research report FEATURE --case WORKSPACE --question TEXT [--write DIR]`, read-only (never edits a workspace, never runs the game; the atlas database is opened read-only). It answers a stated question about a feature across the case's working, original and old trees and the Atlas-indexed mods: what the feature is, who implements it and how, which differences are supported, which conclusions stay hypotheses, and which existing gate (`gates.json`) or command settles each unknown. Every claim carries STATIC, OBSERVED (recorded live runs, captured baselines) or VALIDATED (a gate that is PASS with evidence) and its evidence location; labels are only ever combined to the weakest. Evidence reconciliation tabulates per concept where Atlas and the D-series (archaeology, behaviour map, baselines) both detect, detect alone, or detect and differ; the counts are output, disagreements stay as rows. Also reads REMOVALS.json, dropped-features, `Done/CONTENT_PARITY.json` and `_live` records; a missing input is listed with the command that produces it. Markdown and JSON (schema_version 1) are written atomically; the stdout summary shows the counts.
