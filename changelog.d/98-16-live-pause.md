- `bridgeforge live pause [--reason]`, `live resume` and `live status` keep a pause flag, `live-paused.json`, in the user's local application data (`%LOCALAPPDATA%\BridgeForge`), so every checkout and data root on the machine reads the same one. While it is set, no live, save-reload, duel, smoke, gene boot, java-matrix or `runtime-smoke --execute` run starts on that machine, `live-queue` stops before the next group and keeps its checkpoint, and a refused java-matrix variant stays out of the ledger: a gate left polling in the background cannot launch a game during a pause.
