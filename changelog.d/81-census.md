- Atlas census (ROADMAP-3 81.1): `atlas build` now records, per mod, the `com.fs.*` API classes, methods and fields referenced by its jars (constant pool) and loose scripts (imports and static calls) with counts. New `atlas api-usage SYMBOL_PREFIX` lists the mods using a symbol, how widely, with an example file; new `api how OLD_SYMBOL --old-api JAR --new-api JAR` runs api-diff for a removed symbol and shows which indexed mods use each same-name candidate. STATIC evidence only.
- Save-risk census (81.3): the same pass records persistent-data and memory keys, `onGameLoad` scripts/listeners added without a hasScript/remove guard, `readResolve`/`writeReplace` classes and transient fields of saved classes. New `atlas save-risk [MOD]` prints the leaders, or one mod in detail. STATIC heuristics.
- Library census (81.4): calls into LazyLib, MagicLib, GraphicsLib, Nexerelin, LunaLib and other packages (named by prefix) are recorded per mod. New `atlas libraries` lists per library the functions used, the mods using them and the dependency versions declared in mod_info.json, and the declared-dependency version spread. STATIC.
