## 1. The verdict model

BalanceBench answers exactly one question about one entity at a time:

> Is this entity within the band of vanilla content that is structurally like it — and if not, how far outside, and how sure are we?

Everything else is subordinate metadata. Four **orthogonal** axes are reported. They must never be collapsed into a single number.

### 1.1 Axis 1 — verdict (the headline)

```text
WITHIN_VANILLA_BAND
ABOVE_VANILLA_BAND
MANUAL
```

`MANUAL` is a **valid result**, not an error state. Modded Starsector wires much of its behaviour through scripts and data files; when the evidence cannot support a conclusion the correct answer is `MANUAL`, not a guess.

### 1.2 Axis 2 — severity (only for `ABOVE_VANILLA_BAND`)

Internal vocabulary is deliberately flat and machine-friendly:

```text
LOW       → Slightly overtuned
MODERATE  → Overtuned
SEVERE    → Severely overtuned
EXTREME   → Extremely overtuned
```

Severity is derived from **independent-family counts** (§13.1), never from a summed scalar. `WITHIN_VANILLA_BAND` and `MANUAL` carry `severity: null`.
